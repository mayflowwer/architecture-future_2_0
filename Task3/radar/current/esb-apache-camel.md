Apache Camel используется как интеграционная шина между сервисами. 
Сам фреймворк активно развивается и поддерживается сообществом. 
Однако текущая архитектура шины построена по устаревшему ESB-паттерну, 
который создаёт жёсткие зависимости между системами. 
Оцениваем переход на событийную архитектуру на базе Apache Kafka 
для обеспечения независимого масштабирования доменов.
