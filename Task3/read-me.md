# Инструкция по установке технического радара компании "Будущее 2.0"
1. Удостовериться, что на АРМ установлен Docker / устновить
2. Перейти в директории Task3
   ``` cd Task3```
3. Запустить сборку образа
   ``` docker build --no-cache -t techradar .```
4. После сборки запустить контейнер
   ```docker run -p 3000:3000 techradar  ```
5. Данные тех. радара будут доступны по адресу : http://localhost:3000/techradar/
